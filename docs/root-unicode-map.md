# 无名字形 → Unicode 映射候选（191 个）

目的：把 `roots.json` 里 191 个无名字形（PUA）映射到 Unicode，从而用 LXGW WenKai 楷体渲染。

方法：样本字（包含该字根的字）+ Make Me a Hanzi 的 IDS 拆解共现 + 与命名根的形状相似度。**建议列只是候选，必须对照书图核对**。

字段：`PUA` 字形 id；`样本` 包含该字形的字；`形状` 同键命名根里最像的（分数越高越可信）；`IDS` 样本拆解中出现率最高的部件；`建议` 映射到的 Unicode；`置信` 高/中/低。

> 置信为「高」的也建议扫一眼：通用部件（一、丨、口、日…）容易被共现分析误判。

## 汇总

- 总数 191；高 26、中 78、低 87；有建议 144 个。
- 无键位变体 6 个（见文末）。
