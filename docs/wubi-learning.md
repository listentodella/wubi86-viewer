# 五笔学习路线与必练字表

> **来源**：晓览《五笔字型入门指南》（2025 年 4 月，20 页扫描稿，本文据其 OCR 文本整理）。
> 作者 @晓览 YMPA，《小拆五笔教程》作者，2016 年 CHERRY 杯打字比赛全国第 7 名。
>
> **数据口径**：书中的字数是「老王码 86 词库 + GB2312」口径；本文同时给出**本站微软五笔词库**（27,501 字，含 GBK）的实测值，差异见文末对照表。
> 下文字表全部由本站 `public/data` 现算，可直接用于出题与练习。

## 一、教程的核心理念

1. **先指法、再五笔**：指法必须正确并做到盲打（不看键盘、只看屏幕）。验收标准：**15 秒内按 A–Z 顺序打完 26 个字母**。
2. **规则半小时就能学会，但「学会」不等于「打得快」**：真正的门槛是大量练习。
3. **字根必须记，口诀不必背**：口诀对字根定位帮助有限，「背一万遍口诀，不如把常用字打熟」。
4. **练习内容只练前 500 常用字 + 简单文章**，前 1500 常用字按前 500 / 中 500 / 后 500 分档，**中 500、后 500 可以不练**。
5. **字频决定练习优先级**：前 500 字覆盖约 80% 文本，前 1500 字覆盖约 96%。
6. **三个核心参数**：速度（字/分）、击键（键/秒）、码长（键/字），关系为 **速度 = 击键 × 60 ÷ 码长**。五笔码长约 2.5，全拼在 3 以上。
7. **熟练标准**：打普通文章时击键 ≥ 4、码长 ≤ 3.5、速度 ≥ 80 字/分。
8. **不会打的字就去查**：输入法的拼音反查、拆解图解；把常用字都打一遍，**打到 3000 多字就够**，3000 名之后极少用。
9. **多打词**：二字词码长 2，多字词更短，比单字更快。
10. **用跟打器练、跟人一起练**：比单机闷练更容易坚持；先准确、后速度，循序渐进。

## 二、五笔里的四类「特殊字」与简码体系

- **键名汉字（25）**：每键字根图左上角的代表字，打法「连按四下所在键」；推荐的输入法里通常「按一下 + 选 2」即可。
- **成字字根（99 / GBK 124）**：本身是字、又能作字根的字。打法「报户口 + 首笔 + 次笔 + 末笔」，只有两笔的字全码 3 码。
- **单笔画（5）**：一、丨、丿、丶、乙，打法「报户口 + 该笔画 + LL」。
- **需要拆分的字**：按书写顺序取字根；超过四个字根取「一、二、三、末」；不足四码补**末笔字型识别码**。
- **简码**：一简 25 个、二简 599 个、三简 4397 个（书口径）；**全码 3 码的字也可视作三简**。

## 四、一码 / 二码 / 三码 / 四码：数量与含义

| 类型 | 说明 | 书中（老王码 86 / GB2312） | 本站（微软五笔 / 27,501 字） |
| --- | --- | --- | --- |
| 一简（一码） | 1 键 + 空格 | 25 | 25 |
| 二简（二码） | 2 键 + 空格 | 599（纯 588） | 599（纯 588），前 1500 内 428 |
| 三简（三码） | 3 键 + 空格 | 4397（纯 3812） | 4875 |
| 四码字 | 4 键上屏 | 5931（纯四码 2338） | 全码 4 码 25,580 字 |
| 全码 3 码 | 只有 2 笔的成字字根、只拆两字根的字 | 832 | 1,920 |

前 500 常用字的最短码长分布：1 码 25 个、2 码 215 个、3 码 205 个、4 码 55 个。
前 1500 常用字的最短码长分布：1 码 25 个、2 码 428 个、3 码 818 个、4 码 229 个。

**含义**：日常文本里绝大多数高频字都能用 1–3 码打出，所以「一简、二简、识别码字」比生僻四码字重要得多。

## 六、练习路线（建议顺序）

| 阶段 | 内容 | 验收 |
| --- | --- | --- |
| 0 | 指法、盲打 | 15 秒内按顺序打完 26 字母 |
| 1 | 字根图 + 键名 25 + 成字字根 + 单笔画 | 见到键名/成字字根能直接报码 |
| 2 | 一简 25 + 前 500 常用字 | 一简零思考；500 字正确率 ≥ 98% |
| 3 | 二简 428 + 识别码 173 | 二简条件反射；识别码不再算错 |
| 4 | 前 1500 + 二字词/多字词 | 码长稳定在 3 以下 |
| 5 | 跟打文章，测三参数 | 速度 ≥ 80 字/分、击键 ≥ 4、码长 ≤ 3.5 |
| 6 | 3000 字过一遍，转入实战 | 生稿也能流畅跟打 |

每轮 15–20 分钟，先准后快；错字单独回炉，不要盲目刷速度。

## 七、本站练习页的落地实现

练习页现在按这条路线落地（`/practice`）：

1. **阶段 0 · 指法热身**：按 A–Z 顺序输入，实时计时，目标 15 秒，最佳成绩保存在本机。
2. **阶段 1–5 · 分级练习**（`tiers.json` 由 `npm run data` 生成）：
   - 键名 25 → 成字字根 123 → 单笔画 5 → 一简 25（1 码）→ 常用字 500（全码）
   - → 二简 428（2 码）→ 识别码字 173（全码）→ 常用字 501–1500（全码）→ 常用字 1501–3000（过一遍）
   - 每层一轮 10 题，答对自动进入下一题；每层记录「最佳正确率 / 轮次」，可点「下一层」顺序推进。
3. **跟打练习**：除 7 篇古文外，新增「常用字 500 / 501–1500 / 1501–3000」随机 120 字范本，用任意输入法跟打。
4. **统计**：编码默写与分级练习都显示「平均码长（键/字）」和「题/分」，可直接对照书中的三参数标准。
5. 字表全部由 `scripts/build-data.mjs` 生成到 `public/data/tiers.json`，与文中数字一致（25 / 123 / 5 / 25 / 500 / 428 / 173 / 1000 / 1500）。
